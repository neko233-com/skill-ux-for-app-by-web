## B. 浏览器（有 Playwright / 有浏览器时必做）

最小脚本思路（Python Playwright）：

```python
from playwright.sync_api import sync_playwright
import pathlib
p = pathlib.Path("out.html").resolve().as_uri()
with sync_playwright() as pw:
    b = pw.chromium.launch()
    pg = b.new_page(viewport={"width": 390, "height": 844})
    errors = []
    pg.on("pageerror", lambda e: errors.append(str(e)))
    pg.on("console", lambda m: errors.append(m.text) if m.type == "error" else None)
    pg.goto(p)
    pg.wait_for_timeout(400)
    # 首屏可见
    assert pg.locator(".ux-screen.is-active").count() == 1
    # 至少触发一次跳转
    btn = pg.locator("[data-goto],[data-goto-tab]").first
    if btn.count():
        btn.click()
        pg.wait_for_timeout(300)
    # toast / modal 可触发
    t = pg.locator('[data-act="toast"]').first
    if t.count():
        t.click()
        pg.wait_for_timeout(200)
    pg.screenshot(path="qa.png", full_page=False)
    b.close()
    assert not errors, errors
```

检查点：

1. **无 JS 报错**（pageerror / console.error 全空）
2. **首屏有且仅有一个** `.ux-screen.is-active`
3. **点击任何** `[data-goto]` / `[data-goto-tab]` 后 URL 不变、不白屏
4. **Toast 能出现并自动消失**
5. **390×844**（iPhone 尺寸）与 **1280×800**（桌面）都不横向溢出
6. **截图目检**：主色/圆角/阴影与选中风格一致；文字无截断；对比度可读

### 游戏玩法（使用新玩法 block 时必做）

```bash
node scripts/build.mjs --spec examples/game-genres.spec.json --out tests/artifacts/game-genres.html
node scripts/validate.mjs tests/artifacts/game-genres.html
python tests/e2e_game_qa.py tests/artifacts/game-genres.html
```

- **方向**：游戏未写 `meta.orientation` 时 `#ux-app[data-orientation="portrait"]`；横屏和 `auto` 均实际检查，不能只看属性。
- **视口**：补测 360×800 与 844×390；active `.ux-scroll` 不横向溢出，手牌/商店只在自身容器内横滑。
- **SLG**：选格 → 指令 → 相邻目标后兵力变化；不可达/非法目标不误扣兵力。
- **卡牌**：打出后手牌 -1、费用扣减、目标 HP 变化；费用不足不结算；结束回合恢复并抽牌。
- **打牌**：提示/多选的牌型符合 `rule`；出牌后手牌数和轮次变化，动画期间不能重复结算。
- **自走棋**：购买扣金币、棋子数量守恒、人口限制有效；三合升星与羁绊按上阵状态更新。
- **头顶栏**：使用道具扣库存并结算；`data-ux-overhead` 在设备框内，不遮 Dock 或主操作。
- **动画**：伤害跳字/发牌/受击与状态同步；`prefers-reduced-motion` 下无装饰性无限动画。
- **负路径**：至少测试一次能量不足、人口已满、非法牌型或不可达地块。

## 失败处理

- JS 报错 → 优先怀疑 custom HTML 块，或 spec 里非法字符；重建
- 样式崩 → 检查 `tokens.overrides` 是否写坏了变量（值带了分号/引号）
- 移动端溢出 → 多半是 `custom` 块写死了宽度，改用百分比
