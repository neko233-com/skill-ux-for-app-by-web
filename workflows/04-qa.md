## B. 浏览器（有 Playwright / 有浏览器时必做）

最小脚本思路（Python Playwright）：

```python
from playwright.sync_api import sync_playwright
import pathlib
p = pathlib.Path("out.html").resolve().as_uri()
with sync_playwright() as pw:
    b = pw.chromium.launch()
    pg = b.new_page(viewport={"width": 390, "height": 844})
    errors = []
    pg.on("pageerror", lambda e: errors.append(str(e)))
    pg.on("console", lambda m: errors.append(m.text) if m.type == "error" else None)
    pg.goto(p)
    pg.wait_for_timeout(400)
    # 首屏可见
    assert pg.locator(".ux-screen.is-active").count() == 1
    # 至少触发一次跳转
    btn = pg.locator("[data-goto],[data-goto-tab]").first
    if btn.count():
        btn.click()
        pg.wait_for_timeout(300)
    # toast / modal 可触发
    t = pg.locator('[data-act="toast"]').first
    if t.count():
        t.click()
        pg.wait_for_timeout(200)
    pg.screenshot(path="qa.png", full_page=False)
    b.close()
    assert not errors, errors
```

检查点：

1. **无 JS 报错**（pageerror / console.error 全空）
2. **首屏有且仅有一个** `.ux-screen.is-active`
3. **点击任何** `[data-goto]` / `[data-goto-tab]` 后 URL 不变、不白屏
4. **Toast 能出现并自动消失**
5. **390×844**（iPhone 尺寸）与 **1280×800**（桌面）都不横向溢出
6. **截图目检**：主色/圆角/阴影与选中风格一致；文字无截断；对比度可读

## 失败处理

- JS 报错 → 优先怀疑 custom HTML 块，或 spec 里非法字符；重建
- 样式崩 → 检查 `tokens.overrides` 是否写坏了变量（值带了分号/引号）
- 移动端溢出 → 多半是 `custom` 块写死了宽度，改用百分比
